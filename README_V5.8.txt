Portfolio Tracker V5.8

New:
- Multi-account investment model: Wealthsimple TFSA + Questrade TFSA.
- Existing legacy lots migrate automatically to Wealthsimple TFSA.
- Add Lot now asks which investment account owns the lot.
- Home and Dividends can switch All Accounts / Wealthsimple / Questrade.
- Questrade gets independent holdings, cash, net deposits, dividends, return and chart scope.
- New Net Worth page with both investment accounts calculated automatically.
- Manual Cash/Bank and Liability accounts; CAD + USD supported.
- USD manual balances convert using live USD/CAD.
- Net Worth history starts from V5.8 and saves one snapshot per day while the app is used/refreshed.

Important:
- Questrade holdings are entered as lots; this release does not connect to the Questrade API.
- Bank/liability balances remain manual.
- Cloudflare Worker is unchanged.
