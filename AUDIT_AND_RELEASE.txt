Portfolio Tracker V5.22 — Navigation and UI consistency pass
Base: V5.21.3 (portfolio_chart_scroll_first_v5_21_3.zip)

Changes
- One browser-history navigation coordinator for five tabs and three detail screens.
- Native browser Back / Forward (including iOS browser swipe history when supported) restores the route.
- In-app detail Back buttons use the same back stack; Escape closes the current modal or returns from details.
- Unified controls focus treatment, touch target minimums and modal header geometry.
- Removed duplicate click handlers on holding rows: single delegated handler remains.
- Removed an inert empty delete onclick assignment.
- Bumped service worker cache identity so clients can distinguish this build.

Preserved
- Investment 1D / CIBC NAV price logic and other calculation paths.
- D1/Worker/Cron/Sync Token unchanged.
- Touch/scroll logic from V5.21.3 retained.
- LocalStorage keys and data formats unchanged.

Follow-up audit findings (not silently deleted)
- index.html is a large monolith (~8k lines) with repeated stylesheet overrides and repeated render logic; removing broad blocks without regression testing is risky.
- Separate display styles still exist for CIBC details, transactions, and account charts. Current pass normalizes common controls but not every component.
- Some screens are modals rather than route views, so browser Back on those modals needs separate end-to-end device validation.
- No actual iPhone device validation performed.

Checks
- JavaScript syntax passed node --check.
- Added route-state code is guarded by appNavigationEnabled to avoid initial load history spam.
- This is a navigation/UI cleanup, not a claim of fully native iOS packaging.

Install: Upload index.html and sw.js to same GitHub Pages root; commit/push.
Do not run schema.sql, touch Worker, or restore from cloud for this upgrade.
