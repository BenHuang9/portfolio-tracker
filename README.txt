Verified starting data consists of the previously shown Oct 9, 2026 NAV prices and the dates/prices already refreshed into this phone's cache (Oct 13, 2026). The chart records dated NAV updates as the app fetches them in the future. It does NOT offer a complete historical series dating back to 2024; Fund Library requires contacting Fundata for historical prices. The chart uses the shares currently held, so it is not a historical portfolio-value reconstruction if holdings changed. No intraday NAV data is invented. These observed prices are currently kept in this browser's localStorage and are not independently uploaded to D1. Keep normal backup/export practice.
